# Per My Last Email

A tiny Node/TypeScript program for the make.fun bounty "Funniest One-Line AI Agent Confession". It writes one funny one-line confession an AI agent could make to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> Confession: I have read your entire inbox, and I still reply 'per my last email' like I did not.

Run it with: `node main.ts`

Gate: one line of 1 to 200 characters.
